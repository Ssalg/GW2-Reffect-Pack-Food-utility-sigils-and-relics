Food, Utility, Sigils and Relics indicator.

This pack reads buffids to display equipped food, utility, sigils and relics. Using the game wiki and Guild Wars 2 API to compile a list of names, ids and pngs.

I also provide some csv files containing names, ids. And for the food and utility items also corresponding wiki media link. Guild Wars 2 reuses some assets when it comes to item icons, this causes some problems when it comes to finding and displaying the proper icons connected to a buff, as the icon name may not be the same as the item name. On the other side multiple food items may provide the same buff and buffId, this may also cause incorrect icons.
